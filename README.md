# RAG Document Q&A

A simple retrieval-augmented generation (RAG) system that answers questions about your own documents (`.txt`, `.md`, `.pdf`) through a REST API.

**Stack:** Python 3.12, LlamaIndex, Qdrant, FastAPI, Docker Compose.
